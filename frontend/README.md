# frontend

The browse-and-play UI for the music library. Vite + React + TypeScript.

```bash
npm install
npm run dev     # against the API on http://localhost:5000 (see .env.development)
npm test        # vitest
npm run build   # writes dist/, which Flask serves in production
```
