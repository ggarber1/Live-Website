# Site UI Implementation Plan — one app for every service

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the single-page music UI into the whole site: a router, a nav, a home page, and one page each for todo, habits, recipes and blog, all in one visual language.

**Who it is for:** Greg's girlfriend, Liv. The brief, verbatim: "cute", "not too modern", "vintage chic vibes", "purposeful". Her favourite colour is light purple: the vibe, not the main colour.

**Architecture:** Same `frontend/` app. `react-router` (v7, the `react-router` package, data APIs not used) adds routes and a shared layout. Each service gets `src/<service>/api.ts` plus a page component and tests, following `src/api.ts` and the music components. Flask keeps serving `dist/`; the SPA fallback that Task 6 of the music plan declined is now needed and is added, scoped to non-API paths.

**Tech Stack:** as the music plan, plus `react-router`. Fonts from Google Fonts with local serif fallbacks. Still no UI framework.

## Design language

Written down so every page is built from the same words.

**Feel.** A well-kept paper planner. Cream paper, dark ink, a lavender ribbon. Hairline rules instead of shadows. Serif type, italics for warmth. Small ornaments where a modern app would put an icon. Nothing bounces.

**Palette** (CSS custom properties in `styles.css`):

| Token | Value | Use |
| --- | --- | --- |
| `--paper` | `#f7f2e9` | page background |
| `--paper-2` | `#efe7da` | cards, inputs, alternate rows |
| `--ink` | `#33292e` | text |
| `--ink-soft` | `#7a6e74` | secondary text, rules' labels |
| `--rule` | `#d9cfc4` | borders and hairlines |
| `--lavender` | `#d9c9ef` | the accent: highlights, current row, hover fills |
| `--lavender-deep` | `#7b62a8` | links, primary buttons, focus rings |
| `--rose` | `#c9868a` | delete and errors, used sparingly |

One look only. No dark mode: paper does not have one.

**Type.** Display: Fraunces (Google Fonts, `opsz` on, weights 400 and 600, italic 400), fallback Georgia. Body: Lora, fallback Georgia. Base 17px, line height 1.55. Page titles in Fraunces 600 at 2rem with an italic subtitle in `--ink-soft` beneath. Never all-caps.

**Components,** all in `styles.css`, all by class:

- `.card`: `--paper-2`, 1px `--rule` border, 6px radius, `2px 2px 0 var(--lavender)` offset shadow. That offset shadow is the one flourish; it reads as print, not as UI.
- `.btn`: outlined pill, `--ink` text, 1px `--rule`; hover fills `--lavender`. `.btn-primary`: `--lavender-deep` fill, paper text. `.btn-danger`: `--rose` text, only ever an outline.
- `.field`: inputs and textareas on `--paper-2` with a 1px `--rule` border and a `--lavender-deep` focus ring. Lora, same size as body.
- `.rule-label`: a hairline with a small italic label sitting on it, for section breaks ("today", "earlier").
- Ornament: `❦` (U+2766, the floral heart) after the site name in the nav and as the empty-state glyph. One ornament, used consistently.

**Motion.** 150 ms ease on colour and background only. Nothing moves position.

**Copy.** Sentence case. Empty states are one warm sentence, not an illustration: "Nothing to do. Lovely." / "No habits yet." / "No recipes yet." / "Nothing written yet."

## Routes and services

| Route | Page | API |
| --- | --- | --- |
| `/` | Home: greeting, one card per section with a one-line summary | none |
| `/music` | The existing music page, moved | `/music/*` |
| `/todo` | To-do list | `/todo` |
| `/habits` | Habits with streaks | `/habits` |
| `/recipes`, `/recipes/:id`, `/recipes/new`, `/recipes/:id/edit` | Recipe box | `/recipes` |
| `/blog`, `/blog/:id`, `/blog/new`, `/blog/:id/edit` | The blog | `/blog` |

Blog is the name everywhere: nav, routes, files, API and table. (It was briefly "Journal"; Greg asked for Blog.)

**API shapes, from the blueprints:**

- **todo**: `{id, task, created_at}`. `POST {task}` → 201 `{id}`. `PUT /todo/:id {task}` → 204. `DELETE` → 204. There is no done flag; finishing a task deletes it.
- **habits**: `{id, name, streak, last_completed, created_at}`. `last_completed` is a GMT date string or null. `POST {name}`, `PUT {name}`, `DELETE`. `POST /habits/:id/complete` → 200 with the updated row; a second call the same day returns the same streak. "Done today" is `last_completed`'s UTC date equal to today's local date.
- **recipes**: `{id, title, ingredients: string[], instructions: string[], created_at}`. `POST`/`PUT` take all three; a non-array is 400.
- **blog**: `{id, title, content, created_at}`, newest first. `POST`/`PUT` take both.

`created_at` is an RFC 1123 string from `jsonify`; `src/format.ts` gains `formatDate` for it.
